# aayan-portfolio
A static portfolio for a first-year B.Tech CSE (AI/ML) student at VIT Bhopal, built with vanilla HTML, CSS and JavaScript. The site uses a Cyberpunk 2077 look and includes a hidden "Netrunner" quickhack interface: press Q to run PING, BREACH and OVERHEAT hacks that reveal details about the About, Skills, Projects, Achievements and Contact sections
